## App Flow
   # 1 Quick Docket:
        User creates a docket.
        Enters the number of packets and adds origin and destination locations.
        One truck = One Docket & One Box = One Packet.


   # 2 Docket Print & Gcn:
        Enters docket number.
        Prints the packet and puts it on the box.


   # 3 Manifest:
        Selects origin and destination locations.
        Scans packet QR and barcode numbers.
        Scans all packet numbers and updates the manifest.


   # 4 Arrival:
     '''Note: Before arrival, the user creates the THC number. THC number is only generated in the web admin site.'''
        Enters THC number and updates Arrival.


   # 5 Stock Update:
        Enters THC number and the number of packets.
        User scans the packet and checks the items in it.
        If items are damaged, fills out a pill and clicks a photo to update stock.


   # 6 DRS Update:
        '''Note: Before DRS Update, the user creates the DRS number. DRS number is only generated in the web admin site.'''
        Enters DRS number and updates how many packets are ready for delivery.


   # 7 POD Upload:
        Delivery boy enters packet number, clicks a photo, and updates POD.


   # 8 Docket Tracking:
        Enters Docket number and tracks docket.
